# 软件安全检查清单

**软件：** software-name  
**版本：** v0.1.0  
**安全级别：** S0 / S1 / S2  
**检查日期：** YYYY-MM-DD  
**检查人：**

## 1. 安全级别与边界

- [ ] 已说明为什么属于 S0/S1/S2
- [ ] 已列出用户、外部系统、敏感数据和高风险操作
- [ ] README 已写明认证与权限边界

## 2. 凭证与配置

- [ ] 仓库中只有 `.env.example` 或无敏感值配置
- [ ] 真实密码、Token、Cookie、私钥不在代码、文档、日志和测试数据中
- [ ] 开发、测试、生产使用不同凭证
- [ ] 凭证权限最小化，并明确轮换与撤销方式

## 3. 认证与授权（S2）

- [ ] 服务端统一执行认证
- [ ] 默认拒绝，角色和资源归属均有校验
- [ ] 管理员和高风险操作单独授权
- [ ] Session/JWT 的签名、有效期、签发方和受众均已校验
- [ ] 登录限流、退出、密码重置和权限回收已验证

## 4. 日志与数据

- [ ] 日志不包含 Authorization、Cookie、密码或完整 Token
- [ ] 错误页面不暴露堆栈、连接串或内部配置
- [ ] 测试数据为虚构或已脱敏

## 5. 测试与交付

- [ ] 缺失、错误、过期和撤销凭证测试通过
- [ ] 未登录、越权和跨用户访问测试通过（S2）
- [ ] Secret Scan 已产生对应 PR/Commit 运行记录并通过
- [ ] 未覆盖风险已记录
- [ ] 泄密应急负责人和处置方式明确
