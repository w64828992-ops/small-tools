# 汇云局域网跨传 - 安全说明

Version: 1.1.0
Security Level: S2

## 信任边界

本软件面向公司、家庭等可信局域网使用，不把公共互联网或公共 Wi-Fi 视为可信边界。

v1.1.0 是 Rust + Tauri 轻量版。界面使用系统 WebView，文件传输和网络协议都由 Rust 实现。

## 当前保护措施

### 1. 每次启动临时能力凭证

- 每次启动生成新的 256-bit capability token；
- token 只存在于当前进程内存；
- discovery beacon 会携带 token，供附近电脑发起当前会话请求；
- TCP Offer 必须携带目标电脑当前 token；
- token 不写入 settings.json，不进入日志。

该 token 用于阻止不知道当前会话能力值的盲目连接，但它不是加密身份协议。

### 2. 人工接收授权

发送方连接后只能提交 Offer。

接收端必须由用户明确：

1. 看到发送方电脑名称；
2. 点击“选择位置并接收”；
3. 主动选择保存目录。

在接收方确认之前，发送端不会开始文件数据传输。

### 3. 局域网来源限制

TCP 接收服务只接受：

- loopback；
- RFC1918 IPv4 私网；
- IPv4 link-local；
- IPv6 loopback / link-local / ULA。

公网来源直接拒绝。

### 4. 文件路径保护

接收端会重新验证每一条 manifest 路径：

- 禁止绝对路径；
- 禁止 ..；
- 禁止空路径段；
- 禁止 NUL；
- Windows 上拒绝 Windows 不支持的特殊文件名；
- 解析后的写入目标必须位于用户选择的保存目录中。

### 5. 文件清单与大小校验

- 只接收 Offer manifest 中声明的文件；
- 同一路径不能重复接收；
- 实际文件帧大小必须和 manifest 一致；
- 完成时必须确认声明的所有文件都已收到。

### 6. 写盘保护

- 文件先写入 .huiyun-part-* 临时文件；
- 完整写入并 flush 后才 rename 为正式文件；
- 顶层同名文件或文件夹自动生成 (1)、(2) 等名称；
- 不静默覆盖已有顶层对象；
- symlink 不跟随，发送扫描时跳过。

## 重要限制：没有端到端加密

v1.1.0 为了保持小体积和简单部署，没有加入 TLS/Noise 等端到端加密。

因此同一局域网中具备抓包能力的第三方理论上可能看到：

- discovery beacon；
- capability token；
- 文件传输内容。

结论：仅用于可信公司/家庭局域网，不要在机场、酒店、咖啡店等不可信公共 Wi-Fi 发送敏感资料。

## 电脑名称不是密码学身份

界面中显示的电脑名称用于帮助用户识别设备，不是经过证书认证的身份。安全模型仍然是：可信局域网 + 接收方人工确认。

## 当前未实现

- 端到端加密；
- 设备配对证书；
- 断点续传；
- 跨互联网/NAT；
- 企业集中权限策略。

未来如果需要跨不可信网络使用，应增加经过审计的设备配对与标准加密协议，而不是自行设计加密算法。

## 自动测试

当前 Rust 测试覆盖：

- 私网/公网地址判断；
- path traversal 拒绝；
- JSON 协议帧读写；
- 顶层同名不覆盖；
- manifest 重复文件拒绝；
- 文件和空文件夹扫描；
- 同名顶层对象虚拟重命名；
- discovery 基础参数检查；
- 电脑名称连续更新/持久化；
- symlink 扫描跳过（系统支持创建测试链接时）。

GitHub 正式合并前还必须通过 Secret Scan、Windows 构建和 macOS universal 构建。
